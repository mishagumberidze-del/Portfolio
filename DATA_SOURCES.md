# Data sources and attribution

| Project | Source | Included here |
|---|---|---|
| Olist | [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) | Code, model, aggregate findings and report previews; no raw CSVs |
| Hotel Booking | [Hotel Booking Demand](https://www.kaggle.com/datasets/jessemostipak/hotel-booking-demand) | Code, model, findings and report previews; no raw CSV |
| Online Retail | [Online Retail II Kaggle archive](https://www.kaggle.com/datasets/tunguz/online-retail-ii) | Code and an aggregate analytical report; the downloaded file contains the observed one-year subset described in the project guide |
| NYC Taxi | [Official NYC TLC trip records and zone references](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page) | Code, source-file hash metadata, compact reporting aggregates and derived zone paths; no trip-level Parquet files |
| Spotify Taste | User-authorized local export architecture plus fictional [synthetic demo data](SpotifyTastePrototype/frontend/spotify-taste-web/src/demo-data.ts) | Application source and synthetic examples; no private streaming history, saved-song snapshot, account credentials or tokens |

Raw data must be obtained from its original source and used under that source's terms. This repository does not relicense third-party data, package code or platform assets.
